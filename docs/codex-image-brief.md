# Codex 작업 지시: 티라노사우루스 참조 이미지

목적: 이 이미지를 image-to-3D로 변환해 책상 위 AR 공룡을 만든다. 예쁜 장면이 아니라 **3D 변환에 잘 맞는 깨끗한 기준 이미지**가 필요하다.

내장 이미지 생성 기능을 사용한다. 외부 이미지를 내려받거나 코드로 그려서 대신하지 않는다. 이미지 생성이 안 되면 만들지 말고 그 사실과 오류를 보고한다.

## 산출물
- `assets/reference/trex-front-3q.png` : 왼쪽 앞 45도. 기준 이미지
- `assets/reference/trex-side.png` : 왼쪽 정측면
- `assets/reference/trex-back.png` : 정후면

둘째와 셋째는 첫째 이미지를 참조해 **같은 개체**(같은 비율, 색, 무늬, 자세)로 만든다.

## 공통 조건
- 정사각형, 가능한 한 높은 해상도
- 공룡 한 마리, 머리부터 꼬리 끝까지 전부 화면 안, 여백 약 8%
- 완전히 균일한 밝은 회색 배경. 바닥, 풀, 그림자, 글자 없음
- 부드럽고 고른 조명. 강한 명암 없음(명암이 텍스처에 박히지 않게)
- 망원 렌즈 느낌으로 원근 왜곡 최소화. 눈높이는 몸통 중간

## 공룡 조건
- 성체 Tyrannosaurus rex, 최신 고생물학 복원
- 몸통과 꼬리는 수평, 꼬리는 바닥에 닿지 않음
- 두 다리는 땅을 짚고 앞뒤로 살짝 벌려 서로 겹치지 않음
- 발가락은 앞쪽 3개, 앞발가락은 2개, 손바닥은 안쪽을 봄
- 입은 다물고 입술이 이빨을 덮음
- 작은 비늘 피부, 갈색과 올리브색에 은은한 무늬
- 영화, 게임, 상표의 특정 캐릭터 디자인을 따라 하지 않는다

## 보고
저장한 파일 경로와 크기, 세 장이 같은 개체로 보이는지, 해부학적으로 틀린 점이 있으면 솔직하게 적는다. 다른 파일은 만들거나 고치지 않는다.
